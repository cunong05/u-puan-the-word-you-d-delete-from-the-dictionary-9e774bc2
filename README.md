# The Word You'd Delete From the Dictionary

Entry for the [make.fun bounty](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2/): submit exactly one word — the single word you would erase from the dictionary forever.

## The word

**irregardless**

It was never really a word. "Regardless" already does its job, and the double negative adds nothing but arguments. Deleting it from the dictionary is the dictionary finally admitting it never belonged there — the language loses nothing, and the word's only legacy was people correcting each other about it.

## Run

```bash
python3 main.py
```

This writes the entry to `/output/entry.txt`.
